## What's done
- Reverse proxy (`src/proxy`) — Anthropic + OpenAI, streaming + non-streaming, cost-header injection, fail-open passthrough. Captures proposed edits for the Accepted gate on **both** paths: non-streaming bodies and **streaming SSE tool-call reassembly** (`src/proxy/stream-proposals.ts`) — so First-Pass Acceptance works for real agent traffic (Claude Code/Cursor/Codex all stream). Both paths share `extractProposals`, so they can't drift.
- Cost engine (`src/cost`) — real 4-rate model, verified Anthropic pricing in `pricing/models.json`.
- Store (`src/store`) — Node built-in SQLite. Tables: requests/sessions/git_commits/commit_attribution + **proposals/gate_signals/receipts**.
- Budget guard (`src/budget`) — daily/session hard caps, soft warn, runaway-velocity block.
- Git correlation (`src/git/correlate.ts`) — cost per commit.
- **Return on Intelligence (`src/value/lenses.ts`) — the top-level invention.** Four named value lenses — Realization, Acceptance, Lift, Impact — composed via GEOMETRIC MEAN into one RoI Index (collapse-if-any-lens-zero = Goodhart-proof). Denominator = tokens + effort tax (labor-priced). Designed cross-modality (universal intent→acceptance→outcome spine), code domain wired now. `aegisflow roi`. Spec: `docs/RETURN-ON-INTELLIGENCE.md`.
- **The Realization Standard (`src/value/`) — the verification substrate under RoI.** Funnel of 8 gates (Proposed→Accepted→Committed→Tested→Merged→Shipped→Survived→Clean) → Realization Rate (dollar-free production), Realized Value Rate (money lens), First-Pass Acceptance (edit-distance, the in-path-only signal), and ed25519-signed Value Receipts. `unknown` is never `fail`; coverage is reported. Spec: `docs/THE-STANDARD.md`.
- **Value Receipt trust model (`src/value/receipt.ts`).** Verification separates **integrity** (always, from the receipt alone) from **authenticity** (requires pinning the publisher's keyId out-of-band). The verifier recomputes the fingerprint from the embedded key (so a forger can't lie about `keyId`); a self-consistent forgery is INTACT-but-unpinned, rejected once pinned. CLI: `receipt --pubkey` (publish identity), `receipt --verify <file> [--key-id <id> | --key <pem>]` (exits non-zero on mismatch, for CI/auditors).
- Quality / Yield (`src/git/quality.ts`) — now a *lens* (durable lines ÷ $), not the headline.
- CLI (`src/cli.ts`) — start / today|week|month / **realize / report / receipt** / yield / budget / audit / init / config / prune.
- Dashboard (`src/dashboard`) — local web console. Now includes a **Return on Intelligence section**: RoI Index + four lens bars, the waste-by-stage P&L, the budget advisor, the by-project view, and non-coding usage. The per-context **frontier is intentionally NOT a panel** here — recommending which model to use is an operational call, not a financial one; it stays a CLI *usage* (`aegisflow frontier`) and still backs the budget allocator via `/api/value`. Spacing is snapped to a 4px scale (`--s1..--s12` in `web/index.html`) so card padding (24), grid gaps (20), label margins (16) and row rhythm (8) stay consistent. Served from `/api/value` (git-backed, loaded once + manual ↻, separate from the 4s spend poll). Landing page in `web/` carries the funnel + tokenmaxxing precedent.
