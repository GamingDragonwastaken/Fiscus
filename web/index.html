The problem · "tokenmaxxing"

When tokens become the metric, tokens become the goal.

It's Goodhart's Law, applied to engineering: the moment raw AI usage is treated as productivity, workflows bend to maximize the number instead of the work. Three forces turn that into a runaway bill.

01 / GAMING

The metric gets gamed

Parallel agents left looping unattended, padded prompts, redundant re-summaries — activity inflates while shipped code does not.

02 / AGENTIC LOOPS

Costs compound silently

Agentic tools re-process context across multi-step tool calls. One stuck loop can burn more in an hour than a developer does in a week — with no guarantee anything compiles.

03 / USAGE BILLING

The ceiling is gone

As providers move from flat subscriptions to usage-based pricing, a predictable license cost becomes a volatile, uncapped token bill nobody sees until the invoice lands.

Not hypothetical

In early 2026, Meta ("Claudeonomics") and Amazon ("KiroRank") stood up internal token-consumption leaderboards. Spend spiked roughly 10× in six months with no matching gain in output — and both were quietly shut down. Token-as-metric doesn't just fail in theory; it has already failed in production.

Traditional APM can't help here. A request that costs $0.002 and a bloated loop that costs $0.40 look identical when you only measure latency and errors. The cost dimension is simply invisible.

The new standard · a unit of account for AI work

So how do you know you're using AI well?

Tokens measure consumption. "Lines of code" rewards verbosity. Neither answers the only question that matters: did the spend become a verified, durable, correct outcome? The Realization Standard scores every commit through a funnel of eight objective gates — and production is measured dollar-free. Money is a lens laid on top, never the definition.

What makes it a standard, not a dashboard

Each realized unit emits a portable, ed25519-signed receipt of cost → gate verdicts → outcome. Anyone — a buyer, an auditor, another tool — can verify the claim with the public key and no access to your source. That is the difference between an internal number and a unit of account the industry can trust.

The mathematics · derived, not designed

Four lenses. One index. Valid while you watch it.

Anyone can copy a dashboard. What makes a standard is the derivation underneath it: every formula in Fiscus is forced by stated axioms, every guarantee is verified by simulation in the test suite, and the whole derivation is published. The numbers below are measured, not asserted.

01 · The RoI Index

The composite that cannot be gamed on one axis

Index = 100 · exp( Σ wi ln xi / Σ wi )

Four necessary conditions — did it stick (Realization), did you keep it (Acceptance), did it save time (Lift), did it matter (Impact) — combined as a weighted geometric mean. Not a taste choice: it is the unique form where a zero on any lens zeroes the whole, and an unknown lens is dropped from the mean instead of faked as a pass.

02 · Anytime-valid confidence

An interval you may peek at

A classical interval is only valid if you look once, at a planned sample size. Watched continuously — the way every dashboard is actually used — it breaks. Fiscus's realization rate carries a confidence sequence: the guarantee holds at every glance, so you may act whenever. The honest price, disclosed: a slightly wider band.

03 · The Goodhart alarm

It notices when the metric is being bent

Any metric that matters gets gamed — so the metric ships with its own tamper alarm. The Stability line races a forecaster that only ever sees the past against the best constant-rate story in hindsight; when your realization rate genuinely drifts, the alarm fires and asks the only fair question: did the work change, or did the measuring?

04 · The Shadow Price of Intelligence

What one more AI dollar is worth, right now

μ = β · V* / B

μ ≥ $1 — invest more. μ < $1 — the next dollar returns less than it costs; cut before you grow. Diminishing returns (β) are estimated from your own history when there is enough of it, and fall back to a disclosed default — with the reason printed — when there is not.

How it works

One command. It sits in the path and does the rest.

Fiscus is a reverse proxy you point your tools at — no certificate to install, no traffic intercepted that you didn't explicitly route to it.

1

Point your tools at it

Set ANTHROPIC_BASE_URL and OPENAI_BASE_URL to localhost:8090. Your agents work exactly as before.

2

Every call is metered

It reads the exact usage each provider returns — streaming or not — prices it locally against a versioned rate card, and logs it to an on-device SQLite store. Prompt bodies are never stored.

3

Runaway spend gets capped

Soft thresholds warn; hard caps block with a clean error; a velocity guard halts an agent burning money in a loop — before the bill, not after.

Real-time cost, per request

Watch spend accrue live in a terminal and a local web console. Cost headers come back on every response.

Cost per commit

Correlate spend with the git history it produced — objective cost-per-commit and tokens-per-diff. No invented "efficiency score" to game.

Budgets that actually enforce

Daily, per-session, and runaway-velocity caps — soft and hard — enforced locally, before money is spent.

Local ledger, explicit boundaries

Fiscus sends no product telemetry by default. Proxy traffic goes to the AI provider you configure; proposal capture stays local and can be disabled. Optional team sync is numeric metadata, opt-in.

Not a surveillance tool

Built so developers want it on.

A FinOps tool that developers route around is worthless. Fiscus is engineered as capability, not control: personal dashboards for self-optimization, team views restricted to aggregates, and a hard architectural priority order that never trades away privacy or speed for analytics.

1. Security & data privacy › 2. Latency overhead › 3. Budget enforcement › 4. UI & overrides

If two requirements ever conflict, the higher tier wins. Analytics never compromise the first two. That rule is in the architecture, not the marketing.
