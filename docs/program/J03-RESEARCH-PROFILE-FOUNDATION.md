# WP-J03 research profile foundation

**Status:** `PARTIAL` — research-only foundation added; no production
complexity decision surface is admitted.

`src/research/complexity/profile.ts` implements the first narrow foundation
authorized by the dossier: a deterministic, provenance-bearing vector over
content-free structural and execution observables. It records diff volume,
context tokens, task type, tool count, request/token/reasoning/duration/retry
counts, an input digest, and explicit nulls for uncalibrated epistemic/model
sensitivity and predicted compute. It deliberately emits no scalar complexity
score, routing rule, budget action, or causal explanation.

RED-first coverage is 2/2. The research module has no production imports, no
CLI route, no dashboard route and no benchmark promotion. The ten promotion
rules remain open: prospective train/evaluation separation, calibration,
simple-baseline comparison, held-out decision value, shift abstention, privacy,
decision-time availability, uncertainty coverage and rollback all require
evidence not present in this repository.
