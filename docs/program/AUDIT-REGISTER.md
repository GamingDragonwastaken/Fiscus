## Reconciliation rules

- A `COMPLETED` finding means the repository-internal defect named by that finding is closed. It does not convert external field validation, provider authority, independent security review, assistive-technology testing, publication, deployment, or release identity into repository evidence.
- `SUPERSEDED` means the original proposed remedy would itself overclaim or duplicate a safer architecture; the replacement/refusal is named in the row.
- The dossier packet inventory and this register are separate acceptance systems. A packet label cannot close an Audit II finding unless the final architecture satisfies or deliberately supersedes the finding's epistemic/safety requirement.
- Exact-head and merge-candidate CI are final-gate evidence, not inferred from these status rows.
